## 6. Supabase Network Column Filtering

**Status: Auto-detected from RPC URL — no manual column needed.**

The indexer's `HeliusWebhookManager` and backfill scripts detect network from `SOLANA_RPC_URL`:
- `rpcUrl.includes("devnet")` → devnet
- Otherwise → mainnet

The Supabase `markets` table does not currently have a `network` column.
**Before mainnet launch**, confirm:

- [ ] Markets seeded on mainnet have a distinguishable property (e.g. a `network` column, or separate Supabase project)
- [ ] API routes that list markets do NOT cross-contaminate devnet/mainnet market data
- [ ] If using same Supabase project: add `network` column (`text`, default `'devnet'`) to `markets`, `trades`, `stats` tables and filter in queries

> **Recommendation:** Use a separate Supabase project for mainnet OR add `network` column to all tables and filter in all queries. Mixing is a data integrity risk.

## 7. Helius Webhook URL Verification

**Status: Dynamic — auto-registers on indexer startup.**

`HeliusWebhookManager.start()` calls `api-mainnet.helius-rpc.com/v0/webhooks` to create/update a webhook.
Requirements:
- `HELIUS_API_KEY` must be a **mainnet** Helius key
- `WEBHOOK_URL` must be the public URL of the **mainnet indexer** Railway service (`https://<mainnet-indexer>.up.railway.app/webhook/trades`)
- Railway service must be deployed and reachable BEFORE the webhook registration runs (it runs at startup)

**Checklist:**
- [ ] Deploy mainnet indexer to Railway and get its public URL
- [ ] Set `WEBHOOK_URL` to `https://<mainnet-indexer>.up.railway.app/webhook/trades`
- [ ] Confirm `HELIUS_API_KEY` is a paid mainnet key (Helius free tier has webhook limits)
- [ ] After deploy: verify Helius dashboard shows an active webhook pointing to the mainnet indexer

## 10. Railway Environment Setup Commands

Once mainnet Railway services are created, devops can seed them using the Railway CLI:

```bash
# Install Railway CLI if needed
npm i -g @railway/cli
railway login

# For each service (api, keeper, indexer):
railway link --project <mainnet-project-id> --service <service-name>
railway variables set NODE_ENV=production NETWORK=mainnet FORCE_MAINNET=1
# Then set secrets via dashboard or:
railway variables set HELIUS_MAINNET_API_KEY=<value>
# etc.
```

> **DO NOT** use the existing devnet Railway project ID (`ce5bf2f1`). Create a new mainnet project.
